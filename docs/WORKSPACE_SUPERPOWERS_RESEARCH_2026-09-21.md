## Explicitly NOT importing

- No Superpowers plugin/hook, shell scripts, git worktree machinery, CLI-specific installation, remote background agent pool, parallel worker architecture, model-client copy, extra Room DB or memory brain. Its subagent workflow is optional and can be more expensive; use a single owner and local checks first. Do not switch to paid models for review or fix-loop escalation.
- No local/offline inference, Ollama, on-device Qwen or on-phone model server. Free open-source workflow is not free hosted inference.
- The README describes optional visual companion telemetry via a remotely loaded logo; LYRA should **not** import that visual companion or remote telemetry. No images generated or fetched for this research. No new permissions, network hosts, dependencies or API keys.
- Do not adopt a universal rule that *every* simple user website prompt must wait for multiple clarifying questions: the user's already complete brief is authority. Avoid extra approval for previously approved website-source sharing; require confirmation for newly destructive/security-sensitive operations.
