# LYRA GitHub Connector Broker

This Cloudflare Worker uses the already-installed GitHub App directly. It does **not** use
GitHub user OAuth, Device Flow, a PAT, a GitHub password, or the GitHub App client secret.

## Continuous installation-token flow

1. LYRA generates a random 256-bit pairing key locally and stores it in Android encrypted storage.
2. The user copies that key once into the Cloudflare secret `LYRA_PAIRING_SECRET`.
3. The GitHub App private key is stored once in Cloudflare as `GITHUB_APP_PRIVATE_KEY`.
4. LYRA sends the pairing key over HTTPS to `POST /github/token`.
5. The broker validates the pairing key, creates a short-lived GitHub App JWT, discovers this
   GitHub App's installation for `spy626`, and asks GitHub for an installation access token
   restricted to `spy626/myra-android`.
6. The broker re-verifies the exact account, repository, and `agent/myra-phase-1` branch before
   returning the one-hour installation token to LYRA.
7. LYRA stores the token and pairing key only in Android encrypted storage. When the GitHub token
   expires, the same pairing key can mint a fresh installation token automatically. No repeated
   GitHub sign-in is required.

The GitHub App private key never enters the APK, repository, model prompt, or Android clipboard.

## GitHub App permissions

Current C1 permissions remain read-only:
- Repository contents: Read-only
- Actions: Read-only
- Metadata: Read-only (implicit GitHub App metadata permission)

Write permissions are intentionally not added in this authentication patch.

## Worker configuration

Public vars in `wrangler.toml`:
- `GITHUB_APP_ID`
- `GITHUB_ACCOUNT_LOGIN`
- `GITHUB_REPOSITORY`
- `GITHUB_BRANCH`

Cloudflare secrets:
- `GITHUB_APP_PRIVATE_KEY` — PEM private key generated in GitHub App settings.
- `LYRA_PAIRING_SECRET` — exact 64-character key generated by the LYRA Android screen.

Legacy `GITHUB_CLIENT_SECRET` and `OAUTH_SESSION_SECRET` are no longer used by this broker.

## Endpoints

- `GET /health`
- `POST /github/token`

All responses use `Cache-Control: no-store`.

## Deployment

Cloudflare Workers Builds deploys this broker from `agent/myra-phase-1` with
`/connector-broker/` as the root directory.
